# TRUE NORTH DRAGONS
Retro beat-em-up, fictional Canadian political satire. Play: https://passcool17.github.io/true-north-dragons/

## Héros (v6)
- **Camionneur** : lent, frappe fort, 130 PV, gros recul. Maintenir COUP ~0,6 s puis relâcher = coup chargé. Spécial : **KLAXON DU CONVOI** (onde de choc).
- **Reporter** : rapide, enchaînement de 4 coups (le 3e projette). Double-tap direction = sprint. Arrière + COUP = micro lancé. Spécial : **SCOOP EN DIRECT** (flash qui étourdit l'écran 2 s).
- Armes au sol (COUP dessus) : bâton de hockey (6 coups), pelle à neige (4 coups). Bonus entre les niveaux 3 et 4. Médailles au bilan final.

## Langue / Language (v5)
- Bouton **FR | EN** sur l'écran titre et dans le menu pause (touche **T** au clavier). Le choix est mémorisé ; par défaut, la langue du navigateur.
- Toutes les traductions sont dans `i18n.js` (une seule table FR → EN).

## Commandes (clavier)
J coup · K pied · L saut · **Espace** (ou I, ou J+K) spécial · U saisir/lancer · P/Échap pause · Entrée démarrer · M muet · T langue.
2P : flèches · , coup · . pied · / saut · ; spécial · ' saisir. Une carte « Comment jouer » s'affiche avant le niveau 1 (une fois par session).
